Object Oriented Programming Visual Novel [Unfinished]

Genre: Visual Novel, Edutainment, Single-player

Controls: Keyboard & Mouse

Description:

Created using C# in Unity. Created for my final year project during my undergraduate studies. The game follows the school experience of a group of friends, learning about Object Oriented Programming (OOP). The game has routes that the player can take based on the choices they make, as well as alternate endings based on these outcomes (not currently implemented). The target audience is 1st year university students, who aren't quite familiar with the concepts of OOP.

Pong Clone

Genre: Single-Player, Arcade

Controls: Keyboard

Description:

Created using C# in Unity. A short, 3 stage pong clone created for a piece of course work. The game follows a world class table tennis player (the player), who has been abducted by an interdimensional god of table-tennis. To return home, the player must compete in the tournament and win. Stages increase in difficulty, and are timed.

Stages aren't seperate scenes in the current build, and are instead different prefabs which must be toggled.
